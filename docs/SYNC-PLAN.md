# Сервер синхронизации — план и статус

Статус: **сервер и клиент написаны и проверены локально (версия 16); на сервер Анны ещё не установлены.**
Сервер Анны подходит по ресурсам и правилам (проверено чтением 31.10.2026 по её инструкции `ANNA-SERVER.md`,
которая хранится у Анны, а не здесь): свободно ~3 ГБ памяти и 27 ГБ диска, есть Python 3.12 и sqlite3, Caddy нет,
снаружи открыт только SSH.

## Требования
- Приложение продолжает работать **без интернета**; сервер — только копия и обмен между устройствами.
- **Сквозное шифрование:** телефон шифрует каждую запись ключом синхронизации до отправки. На сервере — только шифр
  и служебные поля (`rid`, `ts`); по `rid` не видно ни тип записи, ни её id. Прочитать данные там невозможно.
- **HTTPS обязателен:** приложение открыто по https, браузер не пустит запросы на http. Нужно имя и обратный прокси
  с сертификатом (Caddy).
- Сервис живёт отдельно от остального на сервере, слушает только локальный порт, ограничен по памяти.

## Как устроено
- **Сервер:** `server/sync_server.py` — Python 3 без зависимостей, SQLite, правило «побеждает более позднее».
  API: `POST /sync` { space, since, push } → { cursor, items, more } (или { reset }); `GET /health`.
  Вход — токен, выведенный из ключа синхронизации. Подробности и установка — `server/README.md`.
  (Сначала планировался Node.js; выбран Python — он есть и на сервере, и на Mac, без установки чего-либо.)
- **Клиент:** экран «Настройки → Синхронизация», шифрование и фоновый обмен — см. `docs/ARCHITECTURE.md`, «Синхронизация».
- **Резервные копии:** данные остаются на каждом устройстве; плюс ежедневная копия базы на сервере (14 дней).

## Развёртывание
Выполняет Claude Code на Mac Анны (у него есть доступ к серверу), строго по `ANNA-SERVER.md` и с её «да»:
1. `/srv/monetka-sync`, юнит systemd, таймер копий (`server/deploy/`).
2. Caddy + `ufw allow 80,443/tcp` (наружу станут доступны только 80/443 → Caddy → сервис синхронизации).
3. Проверка: `/health` по https, `sudo ss -ltnp`, бот жив.

## Решения
- Домен: **сначала бесплатное имя** вида `<адрес-сервера-через-дефисы>.sslip.io` (оно само указывает на сервер,
  Caddy получает на него сертификат). Позже Анна купит **свой** домен: для сервиса — поддомен
  (например, `sync.<домен>`), A-запись на сервер, у Cloudflare — режим «DNS only»; в Caddy меняется одна строка,
  а на устройствах — адрес в «Синхронизации» (ключ и данные те же).
  Имя домена сюда можно записать после покупки, адрес сервера — нет.
- Ключ синхронизации — случайный (152 бита), а не придуманный пароль: его нельзя подобрать, даже если украдут базу.
  Хранится в «Паролях» iPhone.
- Новые «пространства» на сервере: не больше `MONETKA_MAX_SPACES` (2). После подключения устройств Анны можно закрыть
  создание новых: `MONETKA_NEW_SPACES=closed`.
