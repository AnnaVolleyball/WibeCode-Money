# Монетка — правила для Claude

Учёт денег для Анны: PWA без сборки, данные на телефоне. Анна пишет по-русски и чаще всего с телефона.

## Документация — вести и актуализировать всегда
- `README.md` — что умеет приложение и как им пользоваться (для Анны).
- `docs/ARCHITECTURE.md` — как устроен код: данные, хранение, синхронизация, копилка, версии.
- `docs/SYNC-PLAN.md` — план сервера синхронизации и его статус.
- **Любое изменение кода сопровождается правкой документации в том же коммите.** Новая функция → README и
  ARCHITECTURE; изменилась схема данных → раздел «Данные» в ARCHITECTURE; прогресс по серверу → SYNC-PLAN.

## Сервер Анны
- При **любой** работе с сервером Анны сначала прочитай её инструкцию **`ANNA-SERVER.md`** и следуй ей.
  В этом репозитории её нет намеренно: репозиторий публичный. Файл лежит у Анны (`~/.claude/ANNA-SERVER.md` на её Mac).
  Если файла под рукой нет — попроси Анну прислать его, не действуй по памяти.
- Адреса, имена, пути и прочие подробности сервера в этот репозиторий не записывай.

## Как вести работу
- Ветка разработки и публикации: `claude/money-plus-hardcoding-miicnd` (GitHub Pages публикует её корень).
- После изменения файлов подними версию в трёх местах: `APP_VERSION` в `app.js`, `CACHE` и `?v=` в `sw.js`, `?v=` в `index.html`.
- Проверяй в Playwright (Chromium установлен в среде) в размере iPhone 390×844 через `python3 -m http.server`.
  Перед коммитом в консоли страницы не должно быть ошибок.
- Данные пользователя не терять: изменения схемы — через миграцию при загрузке, старые данные должны открываться.
